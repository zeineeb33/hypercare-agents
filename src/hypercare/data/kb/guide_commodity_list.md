# Commodity list and "no offer" results

QuotePort only returns offers for commodities in the commodity list. If a commodity is missing, the search
returns **no offer**.

## Requesting a new commodity
Send the commodity request form to the commodity data team (commodity-data@northwind.example) with the commodity
name, HS code and, for dangerous goods, the IMO class. Lead time is two business days.

## Dangerous goods
Commodities with an IMO class (for example lithium batteries, class 9) are hazardous: once added, they can only
be quoted on a HAZ line (see the special cargo rules).
