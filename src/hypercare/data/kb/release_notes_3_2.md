# TideRate 3.2 release notes

- **SOC flag**: price lines can be flagged for shipper-owned containers.
- **Surcharge breakdown**: the quote PDF lists each surcharge (BAF, LSS, CAF, PSS, HAZ) next to the base rate.
- **Inland tariff table**: inland pre-carriage (INL00) and on-carriage (INL50) rates are managed in TideRate.
- Fix: price lists flagged all-in no longer add surcharges twice.
