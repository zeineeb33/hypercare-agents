# Inland tariff guide

## Inland charges
When the origin is an inland point (for example Lyon), the container is trucked or railed to a gateway port
(for example Le Havre). This leg is charged as **INL00 (pre-carriage)**. Delivery from the port of discharge to an
inland destination is charged as **INL50 (on-carriage)**.

## How to check an inland rate
1. Open the inland tariff table in TideRate.
2. Filter on the inland point and the gateway port.
3. Check that an INL00 (or INL50) rate exists and is valid on the quote date.
4. In QuotePort, open the quote breakdown: the inland charge appears as a separate line.

If the rate is valid in the table, QuotePort adds it automatically to quotes from that inland point.
